# Defendr – Rechtstexte

Dieses Repository enthält die jeweils gültigen Rechtstexte des Discord-Bots **Defendr**.
Die Dateien werden aus dem Bot heraus erzeugt (`legal:build`) und sind identisch mit dem,
was `/privacy` und `/impressum` im Bot anzeigen.

| Datei | Inhalt |
|---|---|
| `privacy.de.md` | Datenschutzerklärung (maßgeblich) |
| `privacy.en.md` | Privacy policy (translation) |
| `impressum.de.md` | Impressum nach § 5 DDG |

Stand und Version stehen in jeder Datei. Ältere Fassungen sind über die Git-Historie und Tags abrufbar.

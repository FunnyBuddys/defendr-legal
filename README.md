# defendr-legal

Public copies of the Defendr legal documents. They are generated by `npm run legal:build` in the Defendr
repository and published by `node apps/bot/scripts/cli.ts legal:publish`; do not edit them here.

The German version of each document is legally binding; the English file is a translation for convenience.
